# QuarterLandingPage

Landing page for Quarter. Plain static site — HTML + CSS, no build step.

## Local development

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Published automatically via **GitHub Pages** from the `main` branch:

- https://kitlogan.github.io/QuarterLandingPage/

Pushing to `main` updates the live site.
